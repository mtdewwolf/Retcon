# Architecture Decision Records

Significant, hard-to-reverse design decisions are recorded here as ADRs — short documents
capturing the context, the decision, and its consequences at the time it was made.

- Numbering: `NNNN-short-slug.md`, sequential.
- Status values: `Proposed`, `Accepted`, `Superseded by NNNN`, `Rejected`.
- An ADR is immutable once accepted; changes of direction get a new ADR that supersedes it.

Use [0000-template.md](0000-template.md) as the starting point.
