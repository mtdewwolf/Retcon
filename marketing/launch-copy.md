## GitHub repository announcement

### Put AI coding agents under supervision

Retcon is an open-source Windows desktop control room for running, supervising, and verifying
the coding agents you already use.

It is being built around a simple standard: work is not done because an agent says so. You
should be able to see what ran, approve risky actions before they happen, review every change,
verify the result with tests and browser evidence, and roll back cleanly when something fails.

Retcon is local-first, provider-neutral, Apache-2.0 licensed, and designed to work alongside
your existing IDE. The project is pre-alpha and not usable yet. Follow the repository or join
early access for milestone updates and the first test-ready Windows builds.

## LinkedIn

AI coding agents can change a repository quickly. The harder question is whether you can see
what they did, stop risky actions, verify the result, and undo it safely.

That is the problem Retcon is being built to solve.

Retcon is an open-source, Windows-first desktop control room for supervising the coding-agent
CLI a developer already uses. It adds isolated worktrees, explicit approvals, attributable
diffs, checkpoints and rollback, browser verification, and durable recovery—without trying to
replace the developer's IDE or require a Retcon cloud service.
