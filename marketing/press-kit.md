# Retcon pre-alpha press kit

## One sentence

Retcon is an open-source Windows control room for supervising, reviewing, and verifying AI
coding agents on your own machine.

## Short description

AI coding agents can make changes quickly; trusting those changes is harder. Retcon wraps the
agent CLI a developer already uses in a supervised workflow with isolated Git worktrees,
explicit approvals, attributable diffs, checkpoints, rollback, browser verification, and
crash recovery. It is provider-neutral, local-first, and designed to work alongside an
existing IDE.

## Key facts

- Status: Pre-alpha; not yet ready for production use
- Audience: Individual Windows developers already using command-line coding agents
- Platforms: Windows 10 and 11 first
- Source model: Fully open source under Apache-2.0
- Pricing: Retcon is free; users bring and pay for their own AI provider
- Architecture: Native Flutter desktop shell, Rust core, managed Chromium service
- Positioning: A control room, not a model, full IDE, or cloud agent platform
- Repository: <https://github.com/mtdewwolf/Retcon>
