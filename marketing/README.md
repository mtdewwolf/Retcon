# Retcon marketing kit

This directory is the source of truth for Retcon's pre-alpha launch messaging and asset use.

- [Brand guide](brand-guide.md) — identity, color, typography, and usage rules
- [Press kit](press-kit.md) — approved descriptions, facts, and media checklist
- [Launch copy](launch-copy.md) — GitHub, X, and LinkedIn announcements
- [Screenshot capture guide](screenshot-capture.md) — the product-proof publication gate

Canonical logo and social exports live under `apps/website/public/assets/`. Run `npm run assets`
from `apps/website` after changing the source artwork.
